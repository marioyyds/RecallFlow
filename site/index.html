把重复的网页工作，交给在真实浏览器里动手的 Agent

你的浏览器办公助手 —— 读、点、填、拖、上传、翻页、跨页搬运

在 GitHub 查看源码 四步快速上手

不是把 HTML 塞给模型，而是在你的真实浏览器里动手：登录态、SPA、内网页面都能读能操作；合成事件失效时经 CDP 派发可信事件。

快速上手

从下载到跑起来，只需要四步。

  1. 加载解压缩的扩展

    打开 edge://extensions/，启用「开发人员模式」，选择「加载解压缩的扩展」并指向项目目录。

  2. 配置 DeepSeek API Key

    点击扩展图标进入设置，填入自配的 DeepSeek API Key。未配置时，知识库仍可正常使用。

  3. 在页面右侧气泡使用

    打开任意网页，点右侧「RecallFlow」气泡，输入指令，或直接选用快捷语句。

  4. 可选：允许访问文件网址

    要操作双击打开的本地 HTML，需在扩展详情里打开「允许访问文件网址」；开启后本地页与普通网页一致。

核心能力

目标是网页上的一切元素：跨域 iframe、Shadow DOM、canvas、虚拟列表、上传 / 拖拽 / 级联下拉、分页与无限滚动。

  • 跨 iframe / Shadow DOM / canvas

    在真实页面的真实结构里定位与操作，不靠对 DOM 结构的猜测。

  • 上传、拖拽与级联下拉

    覆盖自定义日期选择器、文件上传、拖拽排序与级联选择；合成事件失效时经 CDP 派发可信事件。

  • 分页与无限滚动

    翻页、滚动加载之后继续操作，虚拟列表里的目标同样能命中。

  • 跨页搬运

    把信息从一个页面搬到另一个页面，读、点、填、拖可以串成一条流程。

  • 会记、会复用

    站点记忆、技能与宏让重复流程可以复用；数据全部保存在本地。

  • 失败软着陆与可观测

    重复调用或连续失败时只注入反思建议、不摘除工具；逐轮记录工具、耗时与运行轨迹。

每条能力的保证方式（夹具页 / 剧本 / E2E / 技能 / 判据）见 能力清单。

Agent 设计

收到指令后组装上下文，模型输出经工具守卫判定与分级审批，执行结果回到模型；最终答复前还会做一次完成校验。

  1. 收到指令

    组装上下文：意图路由、系统提示、历史与预算。

  2. 模型输出

    工具调用进入工具守卫；最终答复进入完成校验。

  3. 分级审批

    按风险与站点信任分级，通过后执行工具。

  4. 执行并回流

    执行结果回到模型，继续下一轮；无进展时只注入反思建议。

  5. 完成校验

    未达成则注入反思继续，达成后交付回答。

  • 失败软着陆：重复调用、连续失败或无进展时只注入反思建议，不替模型做决定；仅在跨工具持续无进展或预算触顶时收尾。
  • 统一注册表：模型工具列表、权限策略与参数校验共用一份定义。
  • 可靠性与可观测：共享会话、运行锁、卡死检测与动作前后快照校验，逐轮记录缓存命中率与耗时分段。

完整流程图见 页面操作 E2E 流程图。

与外部 AI 集成（MCP）

webfetch 读不到的 SPA、登录态或内网页面，交由 RecallFlow 以真实浏览器会话读取，返回带时间戳与哈希的证据；外部 agent 还能经唯一写通道 page_action 碰页面，形成「读 → 改 → 验」的前端调试闭环。

集成路线的唯一事实来源是 docs/integration-status.md，安装与配置见 recallflow-mcp/README.md。
